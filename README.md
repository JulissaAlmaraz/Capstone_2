# Capstone_2
Data analysis capstone project comparing sales performance across territories

## Project Overview
This project analyzes fictional retail sales data for EmporiUm, a student bookstore retail chain. The goal of the analysis is to compare sales performance, customer activity, and product trends between two sales territories within the South region.

The project was completed using Python in Colab with Pandas, Numpy and Matplotlib.

## Analysis Topics
- Monthly sales revenue
- Store performance rankings
- Top customers and rewards members
- Product category trends
- Transaction analysis
- Marketing recommendations for the next quarter
